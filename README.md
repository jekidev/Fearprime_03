# FearPrime_03

A living research framework for PTSD/CPTSD, fear learning, fear extinction, reconsolidation and adaptive threat control.

## Working thesis

FearPrime uses a functional/adaptive model rather than a simple defect model. Defensive states can be useful in the contexts that trained them. The research goal is therefore not to erase fear, but to improve calibration, discrimination, contextual control and recovery.

Fear extinction is treated as new safety/inhibitory learning that competes with an older fear memory. Exposure is the behavioral engine. Biological interventions are investigated only as potential modifiers of learning, consolidation, retrieval and relapse.

## Main research tracks

- Exposure and inhibitory learning
- Sodium butyrate / HDAC biology
- Dopamine and L-DOPA
- Oxytocin
- Lurasidone receptor-level hypothesis
- Low-dose amisulpride receptor-level hypothesis
- BDNF / TrkB plasticity
- NMDA / D-cycloserine
- Reconsolidation vs extinction
- Autonomic regulation
- Return-of-fear mechanisms
- Measurement and falsification

## Rule

Do not equate immediate calm with successful extinction. The primary question is whether new learning survives time, context change and reinstatement.
