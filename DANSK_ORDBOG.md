# Danske fagbegreber
Dokumentationen bruger danske betegnelser. Tabellen bevarer de engelske søgeord, som bruges i forskningslitteraturen.

| Dansk | Engelsk søgeord | Betydning |
|---|---|---|
| Frygtudslukning / udslukning | Fear extinction | Læring/responsændring ved faresignal uden forventet ubehag |
| Betingning | Conditioning / acquisition | Indlæring af forbindelsen mellem signal og udfald |
| Genkaldelse | Retrieval / recall | Aktivering eller udtryk af tidligere læring |
| Konsolidering | Consolidation | Stabilisering efter ny læring |
| Rekonsolidering | Reconsolidation | Restabilisering efter destabilisering af genaktiveret hukommelse |
| Forudsigelsesfejl | Prediction error | Forskel mellem forventning og faktisk udfald |
| Brud på forventninger | Expectancy violation | Afprøvning, hvor udfaldet afviger fra forventningen |
| Fastholdelse | Retention | Senere bevarelse af læring |
| Spontan tilbagekomst | Spontaneous recovery | Frygt vender tilbage efter tid |
| Kontekstafhængig tilbagekomst | Renewal | Frygt vender tilbage ved kontekstskift |
| Genaktivering efter uvarslet ubehag | Reinstatement | Tilbagekomst efter uparret ubehageligt stimulus |
| Genindlæring | Reacquisition | Ny læring ved genoptagne signal–udfald-parringer |
| Aktivering | Arousal | Fysiologisk eller subjektiv aktivering |
| Kontrolbetingelse | Comparator | Sammenligningsgruppe eller procedure |
| Udfaldsmål | Endpoint / outcome | Det, forsøget faktisk måler |
| Tillægseffekt | Augmentation | Ekstra effekt af en tilføjet intervention |
| Receptorbelægning | Receptor occupancy | Andelen af receptorer optaget af et stof |
| Hudledningsreaktion | Skin conductance response, SCR | Fysiologisk mål; ikke det samme som bevidst frygt |
| Frygtforstærket forskrækkelsesrefleks | Fear-potentiated startle | Forstærket refleks under betinget frygt |
| Udgangspunkt | Baseline | Måling før den relevante intervention |
| Systematiske fejlkilder | Risk of bias | Forhold, som kan forvride et resultat |

CS betegner det betingede signal; US betegner det ubetingede, ofte ubehagelige udfald. PTSD, CPTSD, BDNF, HDAC, DOI og PMID bevares som faglige forkortelser. Lægemiddelnavne er ikke almindelige engelske sætninger.

Udslukning betyder her ikke nødvendigvis, at den oprindelige hukommelse er slettet. Rekonsolidering må ikke bruges som synonym for enhver bedring efter genkaldelse.
