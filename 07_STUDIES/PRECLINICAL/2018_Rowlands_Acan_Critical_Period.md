# Rowlands 2018 — aggrecan som central organisator af PNN og juvenile-like plasticitet
Kontrolleret 2026-09-17 · Evidenstype C/D

[Kilde: PubMed](https://pubmed.ncbi.nlm.nih.gov/30282728/) · PMCID PMC6596198 · DOI 10.1523/JNEUROSCI.1122-18.2018

## Studie
Rowlands D et al. *Aggrecan Directs Extracellular Matrix-Mediated Neuronal Plasticity.* J Neurosci. 2018;38(47):10102–10113.

## Hovedfund
- Conditional deletion af **Acan**, genet for aggrecan, kunne fjerne PNN-struktur.
- Tab af aggrecan flyttede PV+-interneuron-populationen mod en mere plasticitetspræget tilstand.
- Selektiv Acan-deletion i voksen visual cortex genåbnede juvenile-like ocular-dominance plasticity.
- Mere udbredt Acan-targeting forbedrede object-recognition memory i modellen.

## FearPrime-fortolkning
Aggrecan er ikke bare en markør for PNN; det er et strukturelt kontrolpunkt. Det understøtter Lavertu-Jolin-sporet, hvor transient Acan-downregulation omkring extinction ændrer return of fear.

```text
Acan/aggrecan → PNN architecture → PV maturation/stability → begrænset adult remodeling
```

## Begrænsninger
- Primært visual-cortex og generel memory, ikke fear-extinction/PTSD.
- Permanent genetisk loss er ikke samme intervention som transient Acan-siRNA omkring extinction.
- Senere data viser, at cellekilde og developmental compensation betyder meget; se Grødem 2025.
