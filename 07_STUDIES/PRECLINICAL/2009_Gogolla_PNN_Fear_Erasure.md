# Gogolla 2009 — perineuronale net beskytter fear memories mod erasure
Kontrolleret 2026-09-17 · Evidenstype C

[Kilde: PubMed](https://pubmed.ncbi.nlm.nih.gov/19729657/) · PMID 19729657 · DOI 10.1126/science.1174146

## Studie
Gogolla N, Caroni P, Lüthi A, Herry C. *Perineuronal nets protect fear memories from erasure.* Science. 2009;325(5945):1258–1261.

## Hovedfund
- Modningen af chondroitin-sulfat-proteoglykaner (CSPG) til perineuronale net i amygdala sammenfaldt med udviklingsskiftet fra juvenile fear-memory erasure til mere vedvarende voksen-memory.
- Lokal Chondroitinase ABC (ChABC) i voksen amygdala nedbrød CSPG/PNN.
- Når PNN var nedbrudt **før fear acquisition**, blev den efterfølgende memory mere modtagelig for extinction-lignende erasure.
- Timing var afgørende: resultaterne kan ikke reduceres til, at enhver PNN-nedbrydning umiddelbart før extinction forbedrer extinction.

## FearPrime-fortolkning
Studiet etablerer PNN/CSPG som en kausal udviklingsmæssig plasticitetsbremse i fear circuitry, men peger også på, at PNN påvirker **encoding/stabilisering af den oprindelige fear trace**.

```text
PNN modning → mere stabil fear-memory trace → extinction undertrykker snarere end sletter
PNN degradation før acquisition → mere juvenile-like memory lability
```

## Begrænsninger
- Mus, ikke mennesker/PTSD-behandling.
- ChABC er lokal og invasiv; det svarer ikke til systemisk farmakologi.
- Resultatet afhænger af tidspunktet relativt til acquisition og extinction.
- PNN-nedbrydning er ikke selektiv for HDAC2/Acan-mekanismen.
