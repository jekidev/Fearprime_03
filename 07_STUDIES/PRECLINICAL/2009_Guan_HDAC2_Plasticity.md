# Guan 2009 — HDAC2 som negativ regulator af synaptisk plasticitet og hukommelse
Kontrolleret 2026-09-17 · Evidenstype C

[Kilde: Nature](https://www.nature.com/articles/nature07925) · [PubMed](https://pubmed.ncbi.nlm.nih.gov/19424149/) · PMID 19424149 · PMCID PMC3498958 · DOI 10.1038/nature07925

## Studie
Guan JS et al. *HDAC2 negatively regulates memory formation and synaptic plasticity*. Nature. 2009;459(7243):55–60.

Præklinisk musearbejde med neuron-specifik overekspression af HDAC1 eller HDAC2, Hdac2-deficiens, morfologiske synapsemål, elektrofysiologi, hukommelsesopgaver og farmakologisk HDAC-hæmning.

## Hovedfund
- Neuron-specifik **HDAC2-overekspression**, men ikke HDAC1-overekspression, reducerede dendritisk spine-tæthed, synapseantal, synaptisk plasticitet og hukommelsesdannelse.
- **Hdac2-deficiens** gav flere synapser og faciliteret hukommelse.
- HDAC2 var associeret med promotorer for gener involveret i synaptisk plasticitet og hukommelse.
- Kronisk behandling med HDAC-hæmmere forbedrede flere af fænotyperne hos HDAC2-overekspresserende mus, mens HDAC-hæmning ikke yderligere faciliterede hukommelse hos Hdac2-deficiente mus.

## ELI5-mekanisme
HDAC2 kan i denne model forstås som en **bremse på dele af neuronets plasticitetsprogram**:

`HDAC2 ↑ → mindre permissiv kromatin-/transkriptions-tilstand ved relevante gener → færre strukturelle/synaptiske ændringer → svagere plasticitet og hukommelse`

Det omvendte mønster blev set ved Hdac2-deficiens.

## FearPrime-fortolkning
Studiet er et vigtigt mekanistisk holdepunkt for idéen om, at nogle HDAC'er kan begrænse plasticitet. Det viser samtidig, at **HDAC-subtype betyder noget**: HDAC1 og HDAC2 kunne ikke behandles som funktionelt identiske.

Studiet tester **ikke** PTSD, eksponeringsterapi eller fear extinction som behandling. Det dokumenterer derfor ikke, at HDAC2-hæmning forbedrer PTSD hos mennesker. Det dokumenterer heller ikke, at oral natriumbutyrat virker gennem selektiv HDAC2-hæmning i menneskehjernen.

## Kritisk korrektiv
"HDAC-hæmning = mere plasticitet" er for groft. Farmakologiske HDAC-hæmmere kan ramme flere HDAC'er og andre biologiske mål, og genetisk deletion/overekspression er ikke det samme som akut farmakologisk modulation.
