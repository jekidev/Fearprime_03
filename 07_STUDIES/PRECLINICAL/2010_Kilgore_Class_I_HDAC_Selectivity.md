# Kilgore 2010 — butyrat hæmmer primært klasse-I-HDAC'er
Kontrolleret 2026-09-17 · Evidenstype C/D

[Kilde: Nature / Neuropsychopharmacology](https://www.nature.com/articles/npp2009197) · [PubMed](https://pubmed.ncbi.nlm.nih.gov/20010553/) · PMID 20010553 · PMCID PMC3055373 · DOI 10.1038/npp.2009.197

## Studie
Kilgore M et al. *Inhibitors of class 1 histone deacetylases reverse contextual memory deficits in a mouse model of Alzheimer's disease*. Neuropsychopharmacology. 2010;35(4):870–880.

Studiet kombinerede museadfærd med rekombinante humane HDAC-enzymassays for at karakterisere isoformprofilen af blandt andet butyrat.

## Isoformdata for butyric acid
IC50-værdier i rekombinante humane HDAC-assays:

|---|---:|
| HDAC1 | 8,3 µM |
| HDAC2 | 7,0 µM |
| HDAC3 | 4,8 µM |
| HDAC8 | 10,4 µM |
| HDAC4 | 5725 µM |
| HDAC5 | 6403 µM |
| HDAC7 | 4380 µM |
| HDAC9 | 5614 µM |
| HDAC6 | 5881 µM |

Data var gennemsnit fra to assays på separate plader og skal ikke behandles som kliniske koncentrationsgrænser.

## Hovedfortolkning
Butyrat viste en klar **klasse-I-præference** for HDAC1/2/3/8 sammenlignet med klasse IIa og HDAC6 i det anvendte assay.

Vigtigt for FearPrime:

`butyrat ≠ selektiv HDAC2-hæmmer`

HDAC3 var i dette assay numerisk mere følsom end HDAC2, og HDAC1/8 lå i samme lave mikromolære størrelsesorden.

## Adfærdsdel
Systemisk sodium butyrate, valproat eller vorinostat kunne genskabe contextual memory i APPswe/PS1dE9-mus. Dette er et Alzheimer-/hukommelsesstudie, ikke et fear-extinction- eller PTSD-studie.

## FearPrime-konsekvens
Når butyrat kobles til [Lavertu-Jolin 2023](2023_Lavertu_Jolin_HDAC2_Acan_PNN_Extinction.md), skal forbindelsen markeres som **hypotetisk**:

`oral butyrat → central klasse-I-HDAC-eksponering → ? HDAC2 i PV+-celler → ? Acan/PNN → ? extinction-retention`

Kilgore viser biokemisk potent hæmning af HDAC2, men dokumenterer ikke celletypespecifik HDAC2-target engagement efter oral human administration.

## Debug
- Rekombinante enzym-IC50-værdier kan ikke direkte sammenlignes med total plasma- eller vævskoncentration.
- Butyrat kan også påvirke GPCR'er, metabolisme, acetyl-CoA/HAT-balance og andre processer.
- Højere IC50 for HDAC4 betyder ikke, at HDAC4 aldrig påvirkes in vivo; det viser lavere direkte enzympotens i dette assay.
