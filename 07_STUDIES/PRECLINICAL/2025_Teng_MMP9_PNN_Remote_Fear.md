# Teng 2025 — BDNF-TrkB → MMP-9 → PNN-degradering og remote fear updating
Kontrolleret 2026-09-17 · Evidenstype C

[Kilde: PubMed](https://pubmed.ncbi.nlm.nih.gov/41353215/) · PMCID PMC12722755 · DOI 10.1038/s41398-025-03789-3

## Studie
Teng SW et al. *Electroacupuncture facilitates remote fear memory erasure via promoting perineuronal net degradation.* Translational Psychiatry. 2025;15:531.

## Hovedfund
- Remote fear memories var associeret med øgede PNN omkring engram-relaterede celler i prelimbic cortex.
- Lokal ChABC i prelimbic cortex faciliterede post-retrieval extinction/remote fear-memory erasure i musemodellen.
- Electroacupuncture-interventionen øgede neuronal MMP-9 via BDNF-TrkB-signaling og var associeret med PNN-degradering og bedre remote-memory updating.
- Forfatterne rapporterede øget overlap mellem fear- og extinction-relaterede celler efter interventionen.

## FearPrime-fortolkning
Studiet tilføjer et muligt **endogent ECM-remodeling-spor**:

`BDNF/TrkB → MMP-9 ↑ → PNN proteolyse/remodeling → større remote-memory labilitet/updating`

Det er interessant, fordi det forbinder FearPrimes BDNF/TrkB-akse med PNN-remodeling gennem en protease frem for direkte genetisk eller enzymatisk PNN-targeting.

## Begrænsninger
- Musemodel; ikke human PTSD-behandling.
- Electroacupuncture er en kompleks intervention, så MMP-9/PNN er ikke nødvendigvis hele mekanismen.
- Remote post-retrieval extinction er ikke det samme som standard extinction af nyere fear memory.
- MMP-9 har mange substrater og funktioner; global MMP-9-aktivering kan ikke sidestilles med selektiv PNN-remodeling.
