## Vigtig regel
Et Markdown-kort kan være:
1. ét enkelt studie,
2. flere publikationer samlet om ét spørgsmål,
3. en reanalyse af et eksisterende sample.

Filantal må derfor aldrig bruges som studieantal.

Participant/sample-overlap håndteres separat i [Participant Overlap Register](../09_DEBUG/PARTICIPANT_OVERLAP_REGISTER.md).
