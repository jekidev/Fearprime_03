# Schiller 2010 — retrieval før extinction
Kontroldato 2026-09-15 · Evidenstype B

[Primærkilde](https://pubmed.ncbi.nlm.nih.gov/20010606/) · DOI 10.1038/nature08637

## Fund
Humant laboratoriestudie rapporterede forebyggelse af tilbagevendende betinget frygt med en retrieval–extinction-procedure; forfatterne fortolkede fundet som memory updating.

## Debug og kontrolniveau
Læs altid sammen med Chalkia 2020. Laboratorierespons er ikke dokumentation for sletning af autobiografiske traumeminder. PubMed-post og indekseret abstract kontrolleret; denne revision reanalyserer ikke rådata.
