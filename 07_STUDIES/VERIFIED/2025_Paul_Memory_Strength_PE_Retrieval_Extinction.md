# Paul & Asthana 2025 — memory strength × prediction error

**Evidenstype B:** humant laboratoriestudie i raske deltagere.  
**Status:** abstract/metadata kontrolleret 2026-09-18; fuldtekstbaseret effect-size/RoB mangler.

## Originaltitel
*Investigating the effect of memory strength within reactivation-extinction paradigm on cue-dependent amnesia.*

- Journal: Neuroscience. 2025;582:11–21.
- PMID: 40653191
- DOI: 10.1016/j.neuroscience.2025.07.014

## Design
Tre-dages fear-conditioning paradigme med geometriske CS'er og aversive lyd/billede-US. Memory strength blev manipuleret via reinforcement rate (bl.a. 50% vs. 100%), og prediction-error-relaterede retrievalbetingelser blev sammenlignet.

## Registreret fund
Forfatterne rapporterede:
- stærkere betinget SCR efter kontinuerlig end delvis reinforcement under acquisition,
- generelt lavere reinstatement-SCR i PE-behandlede grupper end standardbetingelser,
- return of fear ved stærkere (100% reinforced) memories trods PE-manipulation sammenlignet med 50%-betingelsen.

## FearPrime-fortolkning
Resultatet er konsistent med, at **memory strength og PE kan interagere** som boundary conditions. Det er ikke bevis for en universel styrketærskel, og et enkelt nyere studie kan ikke ophæve tidligere replication failures.

**Foreløbig robusthed:** R1–R2.  
**Foreløbig mekanistisk inferens:** M2.

## Translation
Laboratorie-memory strength operationaliseret via reinforcement history er ikke ækvivalent med varighed, kompleksitet eller autobiografisk betydning af et klinisk traumeminde.
