# FearPrime — Fear Circuit Master Map

Version 0.18 · 2026-09-17

## Formål
Dette dokument er FearPrimes overordnede neurobiologiske kort over trusselsregistrering, kontekst, safety learning, extinction, interoception og defensive output.

Det er en **procesmodel**, ikke et atlas hvor én hjerneregion = ét symptom. De samme områder indgår i flere netværk, og humane fMRI/PET-resultater viser gruppemønstre snarere end individuelle diagnoser.

## Minimumskredsløbet

```text
sensorisk information
      ↓
threat/safety appraisal
      ↓
┌─────────────────────────────────────────────┐
│ Amygdala / salience- og trusselsnetværk     │
│ Insula / interoceptiv og saliensinformation │
│ dACC / trusselsudtryk og kontrolkonflikt    │
└─────────────────────────────────────────────┘
      ↕
Hippocampus ── kontekst, episodisk hukommelse
      ↕
vmPFC/mPFC ── safety/extinction retrieval og regulering
      ↓
Hypothalamus / PAG / hjernestamme / autonomt system
      ↓
defensive outputs + kropslig feedback
      ↺
ny læring om udfaldet
```

Dette diagram er bevidst forenklet. FearPrime bruger det som navigationskort og forbinder derefter hver proces til mere specifikke mekanismer.

## Regioner og processer

### Amygdala
Relevant for:
- læring om biologisk betydningsfulde cues,
- conditioned threat,
- koordinering af defensive responser,
- saliens og værditildeling.

Basolaterale amygdalakomplekser er centrale for associationslæring, mens centrale amygdala-output kan påvirke hypothalamus og hjernestamme.

**FearPrime-regel:** “mere amygdalaaktivitet = mere PTSD” er for simpelt. Aktivitet afhænger af opgave, cue, kontekst, subtype og analyse.

### Hippocampus
Relevant for:
- episodisk og kontekstuel hukommelse,
- diskrimination mellem lignende kontekster,
- retrieval af extinction/safety memory,
- binding af cue til tid og sted.

FearPrime ser derfor hippocampal funktion som central for spørgsmålet:

> “Er dette samme faresituation som tidligere — eller ligner den bare?”

### vmPFC / medial PFC
Forbundet med:
- extinction recall,
- safety valuation,
- regulering af threat responses,
- integration af ny information om forventet udfald.

I klassiske kredsløbsmodeller af PTSD beskrives reduceret vmPFC/mPFC-rekruttering ofte sammen med øget trusselsrelateret limbisk respons, men årsagsretningen kan ikke bestemmes fra tværsnits-fMRI alene.

### dACC
Forbundet med:
- threat expression,
- konfliktovervågning,
- saliens,
- mobilisering af kontrol og respons.

FearPrime adskiller dACC fra vmPFC-funktion i stedet for at behandle hele ACC/PFC som ét “top-down”-system.

### Insula
Relevant for:
- interoception,
- anticipatorisk kropslig betydning,
- saliens,
- integration af kropssignal og forventning.

Et vigtigt FearPrime-spørgsmål er ikke kun om et signal findes, men:

```text
signal → opmærksomhed → fortolkning → forventning → handling
```

### BNST / extended amygdala
Bed nucleus of the stria terminalis og beslægtede extended-amygdala systemer forbindes især med mere vedvarende/uklar trussel og anticipatoriske defensive tilstande.

FearPrime bruger dette som hypotese til at skelne mellem:
- kort, cue-specifik frygt,
- vedvarende usikker threat monitoring.

### PAG og hjernestamme
Periaqueductal gray og andre subkortikale områder indgår i defensive handlingsmønstre som orientering, flight, fight og immobilisering.

Dette kobles til [Adaptive PTSD Model](../05_MODELS/ADAPTIVE_PTSD_MODEL.md) og dissociation/freeze-sporet. Defensive output er ikke i sig selv et moralsk eller viljestyret valg.

### Hypothalamus / HPA-akse
Stresssystemet påvirker:
- cortisol og glucocorticoid-signaler,
- arousal,
- hukommelse og retrieval,
- energimobilisering.

Timing er afgørende: hormonelle effekter på acquisition, retrieval, extinction og consolidation kan være forskellige.

### Striatum og dopamin
Relevant for:
- prediction error,
- saliens,
- reinforcement learning,
- action selection,
- motivation og senere retrieval.

Dette kobler FearPrimes L-DOPA/dopaminspor til læringsmodellen uden at antage, at “mere dopamin = bedre extinction”.

## Netværksniveau
Den klassiske amygdala–mPFC–hippocampus-model er nyttig, men utilstrækkelig alene.

FearPrime registrerer også:
- **salience network**: bl.a. anterior insula og dACC,
- **default mode network**: selvreferentiel og autobiografisk behandling,
- **frontoparietale kontrolnetværk**: kognitiv kontrol og fleksibel regulering,
- koblinger mellem disse netværk.

CPTSD-sporet gør netværksniveauet særligt relevant, fordi negative selvmodeller og sociale modeller ikke kan reduceres til et enkelt “fear center”.

## Læringsfaser skal holdes adskilt

| Fase | Centrale processer |
|---|---|
| Acquisition | cue-outcome association, saliens, autonom respons |
| Generalization | lighed, kategorisering, kontekst, priors |
| Extinction | ny cue-no-threat læring |
| Extinction recall | retrieval af safety/inhibitory memory |
| Renewal | kontekstafhængig return of fear |
| Reinstatement | return of fear efter ny aversiv begivenhed |
| Reconsolidation | mulig destabilisering og opdatering af reaktiveret hukommelse |

Et stof eller en intervention kan påvirke én fase uden at forbedre de andre.

## FearPrime mekanismekæde

```text
Ekstern/interoceptiv cue
        ↓
Perception + prior
        ↓
Threat/safety estimate
        ↓
Kontekstmatch (hippocampus)
        ↓
Saliens/interoception (insula/dACC/amygdala)
        ↓
Valg af defensiv handling
        ↓
Outcome
        ↓
Prediction error
        ↓
Plasticitet / opdatering
        ↓
Konsolidering
        ↓
Senere retrieval i samme eller ny kontekst
```

FearPrime måler helst flere led i kæden i stedet for kun slut-symptomet.

## Kobling til molekylære spor
- BDNF/TrkB → plasticitet og konsolidering.
- NMDA/AMPA → synaptisk læring.
- HDAC/epigenetik → regulering af genekspression og plasticitetsvinduer.
- Dopamin → prediction error, saliens og konsolidering.
- 5-HT-systemer → kontekst-, affekt- og plasticitetsmodulation.
- Endocannabinoider → fear extinction/safety learning i humane og prækliniske modeller.
- Glucocorticoider → stress, retrieval og konsolidering med stærk timingafhængighed.

Se [HDAC/BDNF/5-HT7/dopamin](HDAC_BDNF_5HT7_DOPAMINE.md), [PNN/critical-period reopening](PNN_CRITICAL_PERIOD_REOPENING.md) og [kandidatmatrixen](../04_CANDIDATES/CANDIDATE_MATRIX.md).

## Falsificering og debug
Dette kort svækkes som forklaringsmodel hvis:
1. en foreslået region-proces-kobling kun stammer fra korrelation uden replikation,
2. fund kun gælder én opgave men generaliseres til hele PTSD,
3. dyre- og humane homologiantagelser ikke holder,
4. samme kliniske ændring sker uden den forventede mekanismeændring,
5. netværks- eller beregningsmodeller forklarer data bedre end simple regionmodeller.

FearPrime må derfor aldrig skrive “PTSD skyldes hyperaktiv amygdala” som samlet forklaring.
